Entry for the make.fun **One Word From Grandma** bounty: send one word and nothing else — the single word your grandma would text about AI.

## Run

```sh
node main.ts
```

This writes the entry word to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).

## The entry word

> **Aiyaaa**

The sound a grandma actually makes — and texts — when her grandchild tells her a computer can now talk, think, and write poems. Half shock, half delight, zero understanding of how any of it works.
